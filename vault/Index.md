# Welcome to Parma Wiki

Parma is a lightweight, database-free web wiki layered directly over your Markdown files.

> [!NOTE]
> All notes are stored as standard Markdown (`.md`) files on your local filesystem. Any updates made in Parma, Obsidian, or VS Code reflect in real-time.

## Quick Navigation

- **Culinary & Recipes**: Check out our guide on [[Recipes/Pasta|Artisanal Pasta Making]] and fundamental [[Concepts/Cooking|Cooking Techniques]].
- **Home & Appliances**: Review maintenance schedules in [[appliances/Espresso Machine|Espresso Machine Guide]].

## Getting Started

1. Create new notes using the sidebar navigation.
2. Link pages together seamlessly using `[[Note Name]]` or `[[Folder/Note Name|Custom Label]]` wikilinks.
3. Attach and co-locate media by pasting or uploading images directly into your notes.
4. Explore your knowledge base visually through the interactive graph view.
